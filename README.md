# المصحف المسموع

تطبيق ويب (PWA) لتلاوة القرآن الكريم مع تظليل الكلمة الجارية بالتزامن مع الصوت.

- النص والصوت وتوقيت الكلمات: Quran.com API
- الخط: Amiri Quran (Google Fonts)
- الاستضافة: Vercel — النطاق: atrakchi.contact (نطاق فرعي)

## الملفات
- `index.html` : التطبيق كاملًا
- `manifest.json` : ملف التثبيت على الجوال
- `icons/` : أيقونات التطبيق (عائلة الأطرقجي)

تطبيق مجاني. الشكر لمصادر النص والصوت المذكورة أعلاه.
